# Project 1 Simple Rule-Based Chatbot

## Project Description

The **Simple Rule-Based Chatbot** is a basic AI/ML project developed using Python. It simulates a conversation between the user and the computer by recognizing predefined inputs and providing suitable responses.

The chatbot uses **if-elif-else decision-making logic** to identify user inputs. A continuous **while loop** allows the chatbot to interact with the user until an exit command is entered.

This project demonstrates basic concepts of **Artificial Intelligence, control flow, decision-making, pattern matching, user input handling, and automated responses**.

## Key Features

* **Greeting Handling:** Responds to inputs such as "Hello", "Hi", and "Hey".
* **Predefined Responses:** Provides responses to specific questions and commands.
* **Continuous Conversation:** Uses a loop for continuous interaction.
* **Exit Commands:** Supports commands such as "Bye", "Exit", and "Quit".
* **Unknown Input Handling:** Gives a default response when an input is not recognized.
* **Case-Insensitive Input:** Converts user input to lowercase for easier matching.
* **Dataset Integration:** Uses a dataset containing predefined inputs and responses.

## How This Project Works

The chatbot follows a simple rule-based process:

**User Input → Input Processing → Rule Matching → Response Generation**

1. The user enters a message.
2. The chatbot converts the input into a standard format.
3. It checks the input against predefined rules or dataset values.
4. If a matching rule is found, the chatbot provides the corresponding response.
5. If no match is found, it gives a default response.
6. The chatbot continues this process until the user enters an exit command.

## Technologies Used

* **Programming Language:** Python
* **Concepts:** If-Else, Loops, Functions, String Handling, User Input
* **AI Concept:** Rule-Based Artificial Intelligence
* **Data:** Predefined chatbot dataset

## Objective

The main objective of this project is to understand how a basic conversational system can be created using **Python programming and rule-based AI logic**. It provides a foundation for learning how computers process inputs and make decisions based on predefined rules.

## Conclusion

The **Simple Rule-Based Chatbot** is a beginner-friendly AI project that demonstrates the basic working of a conversational system. It provides a foundation for understanding **decision-making, control flow, pattern matching, dataset usage, and basic AI concepts**.

 # Project 2 Data Classification using AI 

This is the second project from **Project Decodes**, focused on building a basic **Classification Model using Python and Machine Learning**. The project uses a small dataset to understand data handling, supervised learning, model training, and prediction.

## Project Description

The **Basic Classification Model** is a beginner-friendly Machine Learning project developed using Python. The project loads a dataset, understands the available data, prepares it for machine learning, and divides it into **training and testing datasets**.

A simple classification algorithm is then applied to train the model and make predictions. The performance of the model can be evaluated using the testing data.

This project demonstrates the fundamental concepts of **supervised learning, data preprocessing, model training, testing, and classification**.

## Key Features

* **Dataset Loading:** Loads and examines the given dataset.
* **Data Understanding:** Identifies features and the target variable.
* **Data Splitting:** Divides the dataset into training and testing sets.
* **Model Training:** Applies a simple classification algorithm.
* **Prediction:** Uses the trained model to predict the target class.
* **Model Evaluation:** Checks how well the classification model performs.

## How This Project Works

The project follows a basic Machine Learning workflow:

**Dataset → Data Understanding → Train/Test Split → Model Training → Prediction → Evaluation**

1. The dataset is loaded using Python.
2. The data is examined to understand its features and target.
3. The dataset is divided into training and testing data.
4. A classification algorithm is trained using the training data.
5. The trained model predicts results for the testing data.
6. The predictions are compared with the actual values to evaluate the model.

## Technologies Used

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Machine Learning:** Supervised Learning
* **Algorithm:** Classification Algorithm
* **Dataset:** Small CSV Dataset

## Objective

The main objective of this project is to understand the basic workflow of **Machine Learning classification** and learn how a model can be trained using existing data to make predictions.

## Key Skills

* Data Handling
* Dataset Understanding
* Train-Test Splitting
* Supervised Learning
* Model Training
* Classification
* Model Evaluation

## Conclusion

The **Basic Classification Model** provides a simple introduction to Machine Learning. It demonstrates how a dataset can be prepared, divided into training and testing sets, used to train a classification model, and evaluated to understand its performance.
