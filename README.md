# Simple Rule-Based Chatbot

## Project Description

The **Simple Rule-Based Chatbot** is a basic Python project designed to simulate a conversation between a user and a computer program. The chatbot works using predefined rules and responds to specific user inputs such as greetings, questions about the chatbot, and exit commands.

The chatbot uses **if-elif-else decision-making statements** to identify the user's input and provide an appropriate response. A continuous **while loop** allows the chatbot to keep interacting with the user until the user enters an exit command such as *bye*, *exit*, or *quit*.

This project demonstrates fundamental programming and basic Artificial Intelligence concepts such as **control flow, decision-making, pattern matching, user input handling, and automated responses**. Since the chatbot is rule-based, it does not use machine learning or a large language model. Instead, it follows a predefined set of rules to determine its responses.

## Key Features

1. **Greeting Handling:** Responds to common greetings such as "Hello", "Hi", and "Hey".
2. **Predefined Responses:** Provides answers to selected questions and commands.
3. **Continuous Conversation:** Uses a loop to allow multiple interactions.
4. **Exit Commands:** Ends the conversation when the user enters "Bye", "Exit", or "Quit".
5. **Unknown Input Handling:** Provides a default response when the chatbot does not recognize the user's input.
6. **Case-Insensitive Input:** Converts user input to lowercase so that different capitalization does not affect the response.

## Technologies Used

* **Programming Language:** Python
* **Concepts:** If-Else, Loops, Functions, String Handling, User Input
* **AI Concept:** Rule-Based Artificial Intelligence

## Objective

The main objective of this project is to understand how a simple conversational system can be developed using basic programming logic. It helps beginners understand how computers can make decisions based on user input and predefined rules.

## Conclusion

The Simple Rule-Based Chatbot is a beginner-friendly project that demonstrates the basic principles of conversational systems. Although it has limited capabilities compared to modern AI chatbots, it provides a strong foundation for understanding **decision-making, control flow, and basic AI concepts**.
